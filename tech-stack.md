# Tech stack

The full recommended stack, with reasons, is in [BUILD-PLAN.md](BUILD-PLAN.md). This file records what's on the machine.

## Already on this Mac (checked 2026-10-17)
- Apple M2, 16 GB, macOS 26
- Unity Hub + editors: 2022.3.0f1, 2022.3.16f1, 2022.3.62f2, **6000.2.9f1 (Unity 6, planned)**
- Houdini (useful offline: pre-fractured eggshells, cut-face textures)

- **Rokoko Studio: not installed yet** (not on Homebrew; download from rokoko.com/studio)

## Can't use on this Mac

- SteamVR / Vive trackers, Quest Link (no macOS support)
- BEHAVIOR-1K / OmniGibson
- Local TRELLIS.2 / Hunyuan3D texturing (need about 18–24 GB+)
